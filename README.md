## Our games

### [Fireworks Play](https://fireworksplay.com)

A realistic 3D fireworks game where players can explore the town, build fireworks shows, customize effects, and play with friends in multiplayer.

### [Fireworks Show Simulator](https://fireworksshowsimulator.com)

Design and run professional fireworks displays. Place racks, load shells, connect fuses, control the firing system, and watch the show from any viewpoint in a fully 3D world.

[View Fireworks Show Simulator on Steam](https://store.steampowered.com/app/4668450/Fireworks_Show_Simulator)

### Knife Game

A digital version of the finger-stabbing game. Be careful and do not try it in real life.

### Basketball

A free basketball arcade game built around realistic physics, graphics, and sound.
